About

I build software and hardware projects that force me to understand what is happening below the interface. Recent work includes a browser-based data workbench, an ESP32 handheld project, a self-hosted Linux/Nginx site, and LearnCS study tools.

The pattern I care about is concrete: build something, find the constraint, measure or debug it, then revise the design. That is the direction behind both my software work and my move toward embedded systems, digital logic, and computer architecture.

Current focus

  • C and C++ fundamentals
  • Computer architecture and digital logic
  • Embedded systems and microcontrollers
  • Data structures, algorithms, and systems software
  • Building toward FPGA/RTL work
