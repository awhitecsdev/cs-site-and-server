Data Workbench

Structured-data inspection and lookup benchmarking in the browser.

What I built

The workbench loads CSV, TSV, and JSON; normalizes schemas; searches and sorts records; edits rows; profiles columns; exports CSV; and compares repeated exact-match lookup strategies.

Tech

JavaScript, HTML, CSS, Papa Parse, browser Performance API.

Hardest problem

The first sorted/binary benchmark used generalized locale-aware string comparison even for numeric data. That made preprocessing dominate the result. I changed the benchmark so numeric columns use numeric keys, numeric sorting, and numeric binary search while text columns keep string comparison.

The benchmark also reuses the same generated query set for every strategy and reports build time separately from lookup time so preprocessing is not hidden.

Measured baseline

On a 23,220-row dataset with 5,000 successful exact-match queries, the median of five runs before the type-aware sort change was:

  • Linear array: 439.1 ms total
  • Map index: 1.1 ms total
  • Sorted + binary search: 1003.3 ms total, including 844.2 ms of build cost
