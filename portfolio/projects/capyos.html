Overview

CapyOS is a small operating system I’m building on an ESP32-S3 with a TFT display and joystick input. The idea is to have a desk companion that can run mini-games and basic tools like a clock, alarms, and notes.

Core Features

  • Joystick-based menu system for navigating apps.
  • Mini-games like runner-style, Snake, or Pong.
  • Utilities like a clock, alarm, and possibly notes.

What I’m Learning

  • Working with microcontrollers and limited resources.
  • Designing simple UIs for small screens.
  • Structuring code for multiple “apps” on one embedded device.
