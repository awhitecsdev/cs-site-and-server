Overview

LearnCS is a web project where I collect explanations of core computer science topics in one place. The goal is to eventually make it interactive, with visual explanations, code examples, and small quizzes.

Planned Topics

  • Programming basics (C++, Python, Java)
  • Data structures and algorithms
  • Networking and cybersecurity fundamentals
  • History of computing and key figures

What I’m Focusing On

  • Explaining complex ideas in clear, simple language.
  • Designing a structure that’s easy to navigate.
  • Building small interactive demos for each topic.
