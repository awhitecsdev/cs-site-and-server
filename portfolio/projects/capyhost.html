Overview

CapyHost is my self-managed Linux server that hosts multiple sites and services. I use it to learn server administration, security basics, and how to deploy web applications in a more realistic environment than just local development.

Tech Stack

  • Ubuntu Server on DigitalOcean
  • Nginx for web serving and routing
  • SSH with key-based authentication
  • UFW firewall for basic network security

What I Learned

  • How to securely connect to a remote server using SSH keys.
  • How to configure Nginx to serve multiple sites from one machine.
  • How to organize a server file structure for long-term projects.
