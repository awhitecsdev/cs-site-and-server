How this portfolio is hosted

This portfolio isn’t on a drag-and-drop site. It’s served from:

  • /var/www/ on a cloud VPS I manage
  • Nginx configured manually for each path
  • HTTPS certificates via Certbot
  • A custom Flask service for /api

I use this setup to practice real-world deployment instead of only local projects.
