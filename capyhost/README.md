# CapyHost

Legacy web-dashboard experiment related to the CAPY / CapyOS project.

For the current hardware project, see:

- [Live CAPY project page](https://anthonycs.dev/projects/capy/)
- [CAPY technical notes](../docs/CAPY.md)

## What this directory is

This directory contains an earlier simulated device dashboard intended to explore how a handheld device might eventually report status or synchronize with a web service.

It should not be read as the current CAPY hardware architecture. The current project is centered on the physical handheld prototype and its embedded design.
