Capy Runner

STATUS: WIP · T-REX STYLE

An endless runner inspired by the Chrome T-Rex game, but with a capybara instead. Designed first for CapyOS as a jump-and-duck reflex game on a small screen.

CapyOS ESP32-S3 Endless runner

River Rapids

STATUS: CONCEPT · AVOIDANCE

A game idea where you guide a character or boat down a river, dodging rocks and obstacles. Planned for CapyOS first, with a simple JavaScript port later.

CapyOS Obstacle dodging Game design practice

Capy Pong

STATUS: PLANNED

A Pong-style game with a capybara twist. Built to practice basic game loops, collision detection, and input handling on limited hardware.

Pong variant Game loop CapyOS target

Capy Snake

STATUS: IDEA · CLASSIC

A classic Snake-style game adapted for CapyOS. Simple grid movement, growing tail, and score tracking – good for testing input and display updates on the ESP32-S3.

HOW THIS ARCADE WORKS

Each card here maps to a real project I’m building or planning:

  • CapyOS games running on my ESP32-S3 device
  • Future web ports served from /arcade/<name>/
  • Experimenting with game loops, input, and small UIs

ADD A NEW GAME

When I finish a browser version of any game, the steps are:

  • Create a folder like /var/www/arcade/capy-runner/
  • Add an index.html for the game
  • Change the button here into a real <a href="/arcade/capy-runner/"> link
