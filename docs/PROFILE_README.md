## Selected work

### Data Workbench
Browser-based structured-data inspection, editing, profiling, export, and lookup benchmarking.

[Live demo](https://anthonycs.dev/projects/inventory-system/app.html) · [Case study](https://anthonycs.dev/projects/inventory-system/) · [Source](https://github.com/awhitecsdev/cs-site-and-server/tree/main/data-workbench)

The benchmark compares linear scanning, a Map index, and sorted-array binary search while measuring preprocessing separately. A measured bottleneck in numeric sorting led to a type-aware benchmark implementation.

### CAPY
Embedded handheld project built through successive hardware revisions.

[Project page](https://anthonycs.dev/projects/capy/) · [Technical notes](https://github.com/awhitecsdev/cs-site-and-server/blob/main/docs/CAPY.md)

The design moved from an Arduino Mega proof of concept to an ESP32 architecture with a TFT, six-button input, and MCP23017 I/O expansion.
