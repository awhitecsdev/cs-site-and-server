# Anthony White

Computer Science student building systems-oriented software, embedded hardware, and practical tools.

I use [AnthonyCS](https://anthonycs.dev/) as a working portfolio: projects are built, deployed, measured, revised, and documented rather than kept as isolated class submissions.

## Current work

- **Data Workbench** — browser-based structured-data exploration, editing, profiling, and algorithm benchmarking.  
  [Case study](https://anthonycs.dev/projects/inventory-system/) · [Live demo](https://anthonycs.dev/projects/inventory-system/app.html)

- **CAPY** — evolving embedded handheld project built around microcontrollers, TFT graphics, physical controls, I/O expansion, audio, and portable power.  
  [Project page](https://anthonycs.dev/projects/capy/)

- **LearnCS** — study environment for building stronger computer science foundations, with current emphasis on systems-oriented material.  
  [Open LearnCS](https://anthonycs.dev/learn/)

- **AnthonyCS Arcade** — standalone browser games and interaction experiments.  
  [Open Arcade](https://anthonycs.dev/projects/arcade/)

## Technical direction

My current focus is the boundary between software and hardware: C/C++, computer architecture, embedded systems, digital logic, and the path toward FPGA/RTL and SoC work.
