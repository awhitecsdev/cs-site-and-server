Follow an instruction through the machine.

Computer architecture becomes easier when each abstraction is connected to the layer below it: instruction, datapath, control, memory, and physical state.

ISARegistersDatapathControlMemoryPerformance

1. ISA is the contract

An instruction set architecture defines the software-visible machine: instructions, registers, data types, addressing rules, exceptions, and other behavior software can rely on.

RISC-V is useful for study because its base instruction formats are regular and the architecture separates a small core ISA from optional extensions.

2. Example: an add instruction

add x5, x6, x7

1. instruction is fetched
2. fields identify rd=x5, rs1=x6, rs2=x7
3. register file reads x6 and x7
4. ALU performs addition
5. result is written to x5
6. PC advances

The assembly mnemonic is only the top layer. Under it are encoded bits, control signals, multiplexers, register ports, an ALU operation, and clocked state updates.

3. Combinational vs sequential logic

Combinational

Output depends on current inputs. Examples: adders, muxes, decoders, ALU logic.

Sequential

State persists across time. Examples: registers, counters, flip-flops, memories.

A CPU datapath is a combination of both: combinational logic computes candidate values; sequential elements capture architectural state on clock edges.

4. Why the memory hierarchy exists

Fast storage is expensive and physically constrained. Systems therefore use layers:

registers
   ↓
L1 / L2 / L3 cache
   ↓
main memory
   ↓
persistent storage

Programs that reuse nearby data often perform better because caches transfer and retain data in blocks. This is why data layout connects directly to software performance.

Exercise: explain why iterating linearly through a contiguous vector is usually friendlier to caches than chasing nodes in a linked list.

5. Performance requires a denominator

“Faster CPU” is incomplete. Execution time depends on the work performed, instruction mix, cycles per instruction, clock rate, cache behavior, branch behavior, and implementation.

CPU time ≈ instruction count × CPI × clock period

The equation is a model, not a guarantee. Improving one term can affect another.

6. Checkpoint

  • Trace one arithmetic instruction from fetch through write-back.
  • Distinguish the ISA from a specific microarchitecture.
  • Identify which datapath elements store state and which only transform signals.
  • Explain caches through locality rather than “they make memory faster.”
  • Connect a software data-layout decision to hardware behavior.
